🚀 My Portfolio
A sleek, high-performance personal portfolio website built with React.js. This project features a contemporary "Neo-Noir" aesthetic with glassmorphism effects, smooth animations, and a fully responsive layout.

🛠️ Tech Stack
Frontend: React.js (Hooks: useState, useEffect, useRef)

Styling: Custom CSS3 with CSS Variables (Theming)

Typography: Syne & Space Mono (via Google Fonts)

Icons: Emoji-based and custom SVGs

Animations: CSS Keyframes & Intersection Observer API

✨ Key Features
Dynamic Typing Effect: Custom useTyped hook for the hero section titles.

Animated Skills Bars: Progress bars that animate when scrolled into view.

Responsive Design: Fully optimized for Mobile, Tablet, and Desktop views.

Interactive UI: * Smooth scroll navigation.

Glassmorphic navbar with scroll-triggered styling.

Functional contact form with state management and success feedback.

Cyberpunk-style background grid and blurred ambient orbs.
